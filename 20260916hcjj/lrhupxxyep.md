# 孕期哪个阶段是胎儿大脑发育的关键时期？

> 更新时间：2026-09-16 (UTC+8)

前言

成人大脑精细结构的建立，是胚胎干细胞受到精准的基因表达调控、细胞信号传导后，向更为精细的细胞分化并向作用位点迁移的结果。

因此，早期大脑发育包含胚胎原始细胞和神经管的建立、主要大脑分区的形成、未分化神经干细胞向神经元和胶质细胞的分化，以及神经元从产生位置向工作区域的迁移等重要过程。

神经环路的结构和功能从胚胎开始便处于永恒地变化之中，神经元的产生和凋亡、轴突树突以及突触的形成和再塑造，都被遗传基因和环境因素所调控。

尤其是，当基因突变，疾病发生，药物或化学物质暴露时，神经发育过程会受到不同程度的损害。

研究大脑的早期发育，对我们理解神经系统是如何发挥作用，以及诊断和治疗各种由于发育异常而造成的神经系统疾病非常重要。

一、关键的神经系统发育阶段

脊椎动物从早期胚胎发育时期开始，就依循基本的身体中线和轴对称。

美国精神病协会总结的神经系统的发育时间线（含关键事件节点）

从胚胎形成到孕四周，为原肠胚形成，外胚层折叠并内陷形成神经管时期；

从孕四周开始，神经管头部扩张分隔为三个腔隙，分别形成前脑、中脑和隐脑；前脑部位紧接着分隔为两部分，一边最终发育为端脑（大脑皮层区域），另一端最终为间脑（丘脑、下丘脑等）

新生大脑皮层的层状结构也是在这个时期开始发育起来的，这也是我们前面文章老提到的 “cortex layer”，神经干细胞产生并分化为特定神经元或胶质细胞（根据它们所处的分子层域定位）。

此后，神经细胞开始了漫长的迁移，大脑皮层区域的神经元发育会先从深层开始，由深至浅，越靠近皮层表面的层次越晚发生迁移；整体的细胞迁移取决于神经元与神经胶质细胞之间复杂的分子互作作用。

另一小部分神经元起源于基底的原基底神经节核，并向外迁徙至发育中大脑皮层和丘脑处，参与成熟大脑的GABA能神经元的生成。

神经元各就各位后，便开始向外伸长轴突和树突，并开始形成突触了。该突触形成时期从孕中期开始，直到青少年时期。

突触，是大脑进行接受信息和传输信号的结构基础，也是将神经元连接成网，以真正实现大脑功能的关键。我们生活中常说的“学习”过程，其实也是神经突触塑造的结果。（所以，脑子好不好使，就看这个大脑发育时期给不给力了。）

除了突触化以外，大脑发育还存在髓鞘化过程，从28周开始，直到死亡，几乎贯穿人的一生。

二、原始神经系统的建立：原肠胚形成和神经管形成（胎龄2-3周）

在胚胎发育早期（还只是一群细胞时），细胞亚群发生局部内陷，原肠胚形成过程启动。

然后在第18天，胚胎有了三个层次，分别是外胚层、中胚层和内胚层。

中胚层中，最重要的事件是脊索notochord的发育，它由原纹区的中胚层内陷形成，但是脊索只是一个临时结构，早期大脑发育完成后，脊索会消失（它的短暂出现并非毫无意义，因为它是后续大脑结构发育的一个风向标，示中线和保持对称性）；

而覆盖在脊索上方的外胚层结构称为神经板，神经板会逐渐在中线发生折叠，先发育成神经沟，而后形成神经管。

神经管不是一个连续完整的结构，它的腹侧靠近中线的细胞会分化为上皮样的细胞，我们称为“底板”，底板后续会发育成脊髓和后脑的腹侧结构；而与之相应的“顶板”上皮样细胞，后续参与形成脊髓和后脑的背侧结构。

与脊髓和后脑的发育调控模式不同，调节前脑区域结构的信号来源于两方面，一是皮质“下摆”，为前脑-端脑囊泡的背中线的上皮结构域；二是脉络从，其将信号直接分泌到发育中的脑室以调节前脑干细胞增殖和分化。

除了顶板和底板的细胞群外，神经板旁侧，还存在着第三群细胞，为神经脊细胞（neural crest）。神经脊细胞后主要按照四条途径迁徙（如图）：路线1和2分别参与感觉神经节和自主神经节形成；路线3细胞会到达肾脏周围，发挥肾脏神经分泌功能；路线4的细胞最终则发育为头面部的软骨和骨等非神经组织细胞。

三、主要大脑分区的形成

在妊娠早期（胚胎一个月时），神经管会被简单分隔成三段：前脑prosencephalon、中脑mesencephalon和菱脑rhombencephalon（右上图为神经管长段的截面示意图），分别在胚胎的前端、中段和靠后段，后接脊髓。

而在实际胚胎中，我们可以观察到此时胚胎前端末端有一个弯曲处，所以胚胎整体看起来像是“权杖”状。（这个单词很有意思，“cane”，也有“甘蔗“的意思）

胚胎五周时，前脑会被继续分隔成端脑telencephalon和间脑diencephalon结构，中脑还是中脑，后端的菱脑进化为后脑metencephalon和最末端的末脑myelencephalon。

胚胎脑一共五段，最终的大脑将沿着这个框架发育：

端脑--发育成大脑皮层和内脑核团（如基底节、嗅球和海马体结构）等；

间脑--对应成人大脑的丘脑和下丘脑结构，此外，视神经囊泡（视网膜的神经部分）也在此处形成；

中脑--中脑杯盖细胞核；

后脑--最终为小脑和脑桥结构；

末脑--为最终的延髓。

一个本粗糙的神经管结构是如何如此发育成这么复杂的大脑结构的呢？

二十世纪初期，就有科学家经过观察提出大多数神经管是由很多重复性的神经单元组织排列而成的，而它们之所以后续发育为独立的大脑区域，也许是因为这些神经单元各自有特定的”发育标签“。

科学家们于是在果蝇上观察，发现果蝇的身体也是节段性的，他们发现果蝇身体不同节段的分隔是受到不同基因的调控的。

这类具有在胚胎早期分割节段的基因被称为同源基因或同源基因盒，早期在果蝇身上发现的这类基因有bcd、kr、h、以及wg等序列。

我们后来在人的胚胎发育阶段也发现了类似的可以介导发育胚胎神经解剖分隔的相关基因，Hox基因组。

Hox基因序列在染色体上的序列排列与胚胎神经系统结构的形态学特点高度相似，特别是后脑和脊髓区域。

前脑部分，则是受到另一群基因序列的调控（如PAX、DBX、Nkx以及FOX等）。

大脑发育基因的突变和转录异常可能会导致胎儿神经系统发育畸形，如臭名昭著的21三体综合征（唐氏综合征）。

四、神经诱导的分子基础

虽然解码出了调控早期胚胎神经形态学发育的相关基因，对神经发育调控有了一些基础的了解，但是，更为关键的神经诱导过程，即具体神经元和神经细胞的分化以及这些细胞从产生部位迁徙至工作部位的过程，还有待研究。

我们目前能确定的是，神经细胞从早期神经管和神经板上的神经干细胞分化后迁移到特定区域的过程，主要是发生在相邻的结构区域（意思就是说不会跑得很远，特定结构区域内的干细胞后续主要也是”服务”特定范围）。

科学家们对早期胚胎（刚分化出神经外中内胚层时）进行组织移除和移植实验，结果发现，这些组织被从原来部位重新移植到新的部位后，它们可能会保持原始部位的形态和功能特点，也有可能会被新部位组织给”同化“；

而原部位缺失了部分组织后的结局也有不同，大部分会重新生成新的细胞进行功能”补偿“，也有的少数情况是因为缺失而丧失部分功能。

这提示我们，特定区域的神经发育诱导过程，是区域内细胞或组织间互相抱团”信息共享“的结果，因此细胞间的信息交流和信号分子调控尤为关键。

过去三四十年，由于实验技术和手段不断发展，神经学家得以对这部分调节神经诱导的信号分子进行挖掘。

第一个被发现的神经诱导因子是视黄酸（retinoic acid， RA），是维生素A的衍生物。RA信号通路主要调控神经干细胞的分化和细胞迁徙过程。

RA表达异常（如维生素A摄入过量或摄入不足）可能会引起严重的胎儿神经发育不全（神经管闭合不全等）；孕期使用异维A酸可能会导致自发性流产或胎儿畸形。

除RA外，目前被广泛研究的神经诱导因子还有成纤维细胞生长因子FGF家族、骨形态蛋白家族BMPs、Wnt蛋白家族，以及声波海马蛋白Shh等。

Shh蛋白主要在两个环节影响神经系统发育：（1）神经管前中线的闭合；（2）后脑和脊髓部分运动神经元功能的赋予。

与Shh基因突变以及Shh编码蛋白Patched和Smoothened异常有关的疾病有髓母细胞瘤、基底细胞癌等。

现代神经科学研究中，很多时候我们要在细胞培养基中加入一些神经诱导因子来诱导和维持神经细胞的功能，以保证实验顺利进行。比如，我们在培养神经干细胞或者将干细胞诱导分化为神经元时，会在培养基中加入生长因子EGF和FGF等，来稳定细胞的状态。

五、神经干细胞分化

干细胞，具有两大特点：（1）自我更新性；（2）可分化为不同细胞类型，2012年诺贝尔奖被颁给了干细胞的工作。

因此，干细胞研究是近几年很热的话题，也是科研热点。

在神经科学领域，有很多团队也在关注用干细胞来治疗一些神经系统疾病，如帕金森病、阿尔兹海默症等神经退行性疾病。

带来无限可能的同时，也引发了很多乱象。

抛开社会舆论、政治和伦理问题，干细胞的分化倾向性以及分化调控机制问题，目前科学界还未有确切的答案。

在神经系统早期发育中，神经干细胞如何分化为特定结构和特定功能的神经细胞？这个问题我们还在探索中。

首先，神经前体细胞向哪类神经细胞分化（感觉or运动神经元、胶质细胞等)？跟其本身的细胞来源（祖宗是谁？）和其周围的细胞类型（邻居是谁？）有很大关系。

已知神经诱导因子Shh、FGF等在诱导神经分化过程的区域选择中十分重要。

其次，神经分化还有一定的空间顺序（由内向外），如人大脑皮层的不同细胞分层，就是前体细胞在不同时期分化的结构，越深层的皮层细胞产生得越早。

此外，神经干细胞的分化具有时效性，大多数神经干细胞和前体细胞的分化过程，在胎儿出生之前就已经完成，所以很遗憾，如果此后因为年龄和创伤导致神经细胞受损，机体也没有办法产生新的神经元来自我修复。

比起没有办法自我修复，更令人担忧的是，目前我们还没有了解神经细胞是如何变成肿瘤干细胞，导致肿瘤发生的。

六、神经元迁移

神经细胞产生后，要被”发配“到特定脑区进行工作，这是神经环路的作用机制的基础。

首先，如我们前面所介绍的那样，这些细胞内部携带的”定位基因“（Hox序列等）会给细胞指定好区域，拿到分配位置后，细胞要先行”乔装“，我们叫做上皮-间充质转化过程（epithelial-to-mesenchymal transition，EMT），变成间充质样细胞，间充质细胞有着较为”自由散漫”的个性，不受拘束，方便其迁徙过程的进行。（果然，重感情的人不适合行走江湖。）

而在中枢神经系统中的神经元迁徙，还有个重要的特点，就是受到放射性胶质细胞的GPS引导。

七、感觉基板sensory placode

哺乳动物的早期大脑发育还有一个重要的事件，那就是颅骨和表面的基板的限定和分化。

胚胎发育过程中，外胚层区域会部分增厚，形成一部分感觉器官，这些结构最后会发育为嗅囊、科蒂氏器、晶状体、角膜等特定器官的感受器。

这些基板结构（其实是感觉神经元群体）都具有直接从环境中转导特定类别感觉刺激的独特能力，介导初级信息在大脑中进一步处理。

因此，基板的形成是建立感觉信息“进入”中枢神经系统的“基线”。

每一个从外胚层表面分化的基板都会与神经嵴细胞发生诱导相互作用，从而推动其进一步分化。

随后不同部位的基板的分化各不相同，躯体感觉神经元产生机械感觉、痛温觉（这些感觉在外周都有特定的感觉传导末梢）；

在嗅基中，外胚层细胞先产生局部神经干细胞，而后分化为双极感觉神经元，表达单气味受体；

在耳板中，外胚层细胞产生听毛细胞，而晶状体的基板则不产生神经元，它向内陷产生近透明的细胞，这种透明细胞可分泌透明的基质形成晶状体结构，晶状体结构可以传导并聚焦光源，且可以灵活适应不同的视焦平面。

这些基板神经元细胞此后合并神经嵴细胞形成神经节。

小结

1. 早期神经系统的发育主要分为大脑分区、细胞分化和细胞分布三大事件；

2. 细胞迁徙是大脑神经环路分级（前面学过的第一级、第二级神经元）以及突触结构形成的基础；

3. 细胞的命运不是由它自己所携带的基因单独决定的，其功能还受到周围信号、转录后调控等调节；

4. 感觉基板的规范和分化是早期神经系统分化的关键环节，基板的建立是早期胚胎的中枢神经系统与外周建立联系的关键。
