# 宝宝长这种透明小丘疹，家长一定要小心~~

> 更新时间：2026-09-17 (UTC+8)

一粒粒的、白色的、透明的、有着珍珠光泽的、小米大小的丘疹，这不是痱子吗？怎么说是传染病？！

8个月大的明明（化名）近段时间反反复复长皮疹，在家附近医院看了说是痱子，结果用了很多药都不见好，反而越长越多。近日，明明妈妈带孩子来我院皮肤科就诊，医生确诊为“水瘊子”，一种传染性疾病。

“孩子没有明显的瘙痒，用了治疗痱子的药不但不好，反而越长越多，应该排出痱子的可能性。”接诊的张晶医生介绍。

经检查，明明的颈部、背部及后枕部，长满了白色的、透明的、有着珍珠光泽的、小米大小的丘疹，肉眼看起来和痱子非常的接近。

张晶医生介绍，这种透明的皮疹看起来和“痱子”非常相像，但其实是另外一种疾病，名字叫做“传染性软疣”，俗称“水瘊子”，但是否是“水瘊子”还要借助皮肤镜检查进一步确诊。

皮肤镜下可以看到，明明脸上的疹子是一枚枚光滑的隆起物，周边呈半透明状态，花冠样血管扩张，中间可见脐凹，内含白色栓状物—软疣小体，完全符合传染性软疣的皮肤镜下表现。

张晶医生告诉明明妈妈，“水瘊子”可以自体传染，也可以通过接触传染给他人。

明明妈妈不禁感到疑惑：这种传染性疾病究竟是怎么引起的？家里人一直很注意卫生，家里其他人身上也没起过这种疹子，宝宝究竟是怎么传染到的呢？

张晶医生解释说，传染性软疣的病原体叫做传染性软疣病毒，主要的传播方式是直接接触传播，性接触也可传播，还可通过一些公共设施如泳池、温泉池、公共浴室传播。

明明妈妈听了解释，突然想起3个月前曾带宝宝游过泳，之后开始发病，估计就是那时候感染了传染性软疣。

经过皮肤科医护人员的精心治疗和护理，现在明明的传染性软疣已经全部消退，没有留下瘢痕，目前还在门诊定期观察有无新发软疣。

**【知识链接】**

01
**传染性软疣****有哪些症状****？******

传染性软疣多发于儿童和免疫力低下者，尤其是由湿疹、特应性皮炎患者更容易患病。潜伏期为1周-半年，所以患者感染了病毒后不会立即发疹。

儿童感染了传染性软疣病毒后，皮疹好发于手背、四肢、躯干及面部。典型的皮疹表现为直径3-5mm不等的半圆形丘疹，呈灰色或珍珠色，表面有蜡样光泽，中间有个脐凹。

发现宝宝身上出现了经久不褪的白色蜡样光泽皮疹后，要及时就医，切不可自行盲目用药，切忌自行反复搔抓或抠除皮疹，造成皮疹大面积传染。

02
**怎么治疗****呢****？******

传染性软疣主要采取的是物理治疗联合外用药物治疗的方法。我院采取的是疣体局部刮除疗法，具有见效快、损伤小、出血少、易被患儿及家长接受的优点。

特别提醒：由于传染性软疣病毒从感染到发病具有一定的潜伏期，患儿初次治疗后还需动态观察皮疹有无反复发作，门诊定期复诊，不要认为治疗1次就不需再治疗。

03
**治疗后****该如何****护理****？******

1. 注意个人卫生，治疗期间可洗淋浴，洗澡手法应轻柔，避免用毛巾或洗澡巾大力揉搓皮肤，贴身衣物勤换洗，并注意消毒，不与家人共用毛巾、浴巾。

2. 出疹时避免搔抓皮肤，可给宝宝戴上手套，防止病毒自身接种传播。

3. 为了防止扩散，患者不要到公共浴池、温泉、游泳池等地游泳、洗浴。

4. 成年人出疹期间避免同房，注意两性卫生，性伴侣也应去医院检查。

5. 注意休息、适当活动、保持良好的心态，提高机体免疫力。
